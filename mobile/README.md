# Sinfonie for iPhone and Android

The phone companion to the Mac app: the list of your workspaces, their conversations, and the
prompts agents are waiting on, with push notifications you can answer without opening the app.
Expo (React Native), one codebase for both stores.

## How it connects

The Mac shows a QR in Settings → Phone. It carries a random key; the app derives the relay room
id and auth token from it and encrypts every message with it (AES-GCM through `@noble/ciphers`,
identical to the desktop's WebCrypto envelopes). `relay.sinfonie.dev` forwards envelopes it
cannot read. The key is kept in the device keychain (`expo-secure-store`).

Push goes through Expo's push service: the app registers its Expo push token with the relay room,
and the relay posts to `exp.host` when the Mac asks for a notification. Permission pushes use the
`sinfonie.permission` category with Allow / Deny actions that reply straight to the relay.

## Develop

```
cd mobile
npm install
npx expo run:ios        # builds the native project and starts it in the simulator
npx expo run:android
```

Push needs a real device and an EAS project id (`npx eas init` writes it into `app.json`); the
simulator does everything else. `SINFONIE_RELAY_URL` on the Mac points both ends at another relay.

## Ship

```
npx eas build --platform all --profile production
npx eas submit --platform ios
npx eas submit --platform android
```

`eas.json` has `development`, `preview` and `production` profiles. Bundle id and package are
`dev.sinfonie.app`. `ios/` and `android/` are generated by `expo prebuild` and not committed.
