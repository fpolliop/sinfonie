Sinfonie

One workspace across all your repositories.

Sinfonie runs Claude Code in isolated workspaces the way Conductor does, with one difference that matters for full-stack work: a workspace creates a worktree on the same branch in every repository you pick, and a crew of models works across them.

Download for Mac Release notes

Apple Silicon. Needs a Claude Code login and git.

Multi-repo workspaces

Frontend and backend on one branch, side by side, created and archived together.

A crew of models

An orchestrator delegates exploration, tests and implementation to cheaper or more focused agents.

Review cockpit

AI review of open pull requests, findings you approve one by one, posted as a single GitHub review.

Jira, GitHub, MCP

Start work from a ticket, see PR status and review threads, hand Claude the MCP servers each space needs.

Spaces

Personal, work, client: each space owns its repos, Jira, accounts and defaults.

conductor.json compatible

Your existing setup, run and archive scripts keep working, ports included.

Installing an unsigned build

Sinfonie is not notarized yet. On first launch macOS may block it: right-click the app, choose Open, then Open again. On recent macOS versions the option is under System Settings → Privacy & Security → Open Anyway.

xattr -d com.apple.quarantine /Applications/Sinfonie.app   # alternative, from a terminal
