Sinfonie

Slack walkthrough

Installation, OAuth flow, setup and functionality, in order. Sinfonie is a macOS desktop app; download at sinfonie.dev/download.

1. Sign in with Slack

Settings → Integrations → Slack → Sign in with Slack. The app shows the Slack authorization link; the user opens it in the browser (or copies it to a browser that is signed in) and approves the requested user scopes on Slack's page. No bot, no workspace install step.

2. Connected

Slack redirects to sinfonie.dev, which hands the authorization code back to the app. The app exchanges it for the user's token and shows who is connected. Disconnect removes the token from the Mac.

3. Choose channels to watch

In a space's On call page the user searches their channels and adds the ones to watch, as support requests or alerts, then enables the watcher. Only these channels are ever read, at most once per minute each.

4. Incidents, triage and approved replies

Each new message in a watched channel becomes an incident. An AI model (the user's own provider) writes a triage report and may draft a reply. Nothing is posted until the user presses Send in thread as you on that exact message; Dismiss discards it. Follow-up questions run the same read-only investigation.

Test steps

  1. Install Sinfonie from sinfonie.dev/download (macOS, Apple silicon; signed and notarized). Open it and skip setup, or create a space named Test.
  2. Settings (⌘,) → Integrations → Slack → Sign in with Slack → Open in browser → approve. The page turns to “connected as …” within seconds.
  3. Settings → Spaces → Test → On call: search a channel you are a member of, add it as “support requests”, tick “Watch the channels below”.
  4. Post a message in that channel. It appears in the On call view (sidebar) within one to two minutes.
  5. Open the incident. With an AI provider configured a triage report and possibly a draft reply appear; without one the incident is listed untriaged. Press Send in thread as you to post the draft, or Dismiss.
  6. Settings → Integrations → Slack → Disconnect removes the token.
